# Documentación

Manuales educativos y profesionales para operar con la arquitectura de trading automatizado.

| Guía | Propósito |
|---|---|
| `metodologia.md` | Cómo se desarrollan y validan los EAs (Walk-Forward, out-of-sample, robustez). |
| `gestion-de-riesgo.md` | Sizing por riesgo, Circuit Breaker diario, drawdown y cómo ajustarlo a tu cuenta. |
| `despliegue-demo-a-real.md` | Checklist para pasar un EA de demo a cuenta real. |

> Lee primero `metodologia.md` y `gestion-de-riesgo.md` antes de montar cualquier estrategia.
